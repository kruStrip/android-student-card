# Android: карточка студента

Приложение хранит и показывает информацию о студентах и курсах; код разложен на слои `data` и `domain`.

**Стек:** Kotlin · Android Studio · Gradle · Room

## Что внутри

- `app/` — экраны: студенты, курсы, регистрация, профиль
- `data/` — Room, DAO, DTO и реализации репозиториев
- `domain/` — модели, интерфейсы репозиториев и use case

## Запуск

Открыть проект в Android Studio и запустить на эмуляторе или устройстве.
