# Android: карточка студента

Приложение хранит и показывает информацию о студенте; код разложен на слои Data и Domain.

**Стек:** Kotlin · Android Studio · Gradle

## Что внутри

- `app/` — приложение
- `Data/`, `Domain/` — данные и бизнес-логика

## Запуск

Открыть проект в Android Studio и запустить на эмуляторе или устройстве.
